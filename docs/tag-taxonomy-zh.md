# 文章标签体系

Zenfeed 使用受控中文词表标记文章主题。内容类型继续由 `category` 表示，`tags` 只描述文章讨论的内容，避免把“AI 论文”“AI 博客”“社交网络”“图片”等重复作为标签。

每篇文章选择 1-3 个标签。通常选择 1-2 个核心主题，并在必要时补充 1 个研发阶段或应用语境标签。公司名、人物名、模型名和产品名不进入标签体系，避免标签数量随资讯增长失控。

## 核心主题

| 标签 | 使用范围 |
| --- | --- |
| 大语言模型 | 语言模型架构、能力、推理和语言建模研究 |
| 智能体 | Agent、工具调用、规划、记忆、多智能体与计算机操作 |
| 多模态 | 跨文本、图像、视频或音频的统一理解与推理 |
| 生成式媒体 | 图像、视频、3D、音乐和内容生成 |
| 计算机视觉 | 视觉理解、检测、分割、渲染和空间推理 |
| 语音音频 | 语音识别、合成、克隆、音频理解和翻译 |
| 机器人与具身 | 机器人、操作、导航、运动控制和具身策略 |
| 数据与检索 | RAG、搜索、Embedding、知识图谱、数据库和数据工程 |
| AI 编程 | 代码生成、Coding Agent、软件工程和开发者工具 |
| AI 基础设施 | 算力、云平台、训练基础设施、编排和可观测性 |

## 研发阶段

| 标签 | 使用范围 |
| --- | --- |
| 训练与微调 | 预训练、后训练、强化学习、蒸馏和数据合成 |
| 推理与部署 | 推理优化、量化、缓存、服务和端侧部署 |
| 评测与基准 | Benchmark、评测方法、Judge 和能力测量 |
| 安全与对齐 | 模型安全、对齐、越狱、误用和可信性 |
| 网络与隐私 | 网络安全、漏洞、密码学、隐私和滥用防护 |

## 应用语境

| 标签 | 使用范围 |
| --- | --- |
| 产品发布 | 新模型、API、功能或平台正式发布与更新 |
| 开源生态 | 开源模型、框架、数据集、协议和社区协作 |
| 企业应用 | 企业工作流、客户案例、业务自动化和组织落地 |
| 行业与商业 | 市场竞争、融资、成本、商业模式和产业趋势 |
| 政策治理 | 法规、公共政策、版权、治理与社会影响 |
| 科学与教育 | 科研发现、AI for Science、教育和人才培养 |
| 自然与影像 | 自然、生态、摄影和以视觉作品为主体的内容 |
| 观点评论 | 对技术、行业、产品或治理问题的分析与评论 |
| 人物动态 | 订阅人物的经历、工作状态和非技术近况 |

## 输出约束

- 输出必须来自上述词表；服务端兼容中英文逗号和逗号后的空白。
- 信息不足、只有链接或只有活动报名信息时不强行生成标签。
- 服务端通过正则校验完整输出；包含未授权标签或解释文字的结果不会写入 `tags`。
